HeMi Dark - a dark, minimal skin in the style of Windows 11 for VLC 3.0.x
==========================================================================

The easy way: HeMiDark-Setup.exe picks the right file and sets it in VLC
(https://github.com/Hemal1k/HeMiDark/releases/latest). By hand:

1. Pick a colour (folder) and the file for the scaling of your screen
   (Windows Settings > System > Display > Scale):

     HeMi-Dark-<colour>-100.vlt   100 % (usual Full HD)
     HeMi-Dark-<colour>-125.vlt   125 %
     HeMi-Dark-<colour>-140.vlt   140 %
     HeMi-Dark-<colour>-150.vlt   150 %
     HeMi-Dark-<colour>-175.vlt   175 %
     HeMi-Dark-<colour>-200.vlt   200 % (4K)

   Colours: blue, teal, green, yellow, orange, red, pink, purple, graphite.

2. VLC > Tools > Preferences > Interface > "Use custom skin" > choose the .vlt > Save > restart VLC.

Back to the usual look: menu (the button at the top left) > Tools > Preferences > "Use native style".

Subtitles: VLC 3 has no menu of its own for subtitles; the subtitles button opens the main menu
(Subtitle > Sub Track). The key V cycles the subtitles, B the audio tracks.

The font Selawik inside the skins is under the SIL Open Font License (fonts/Selawik-LICENSE.txt in each .vlt).
